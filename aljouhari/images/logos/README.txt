Client logo files
=================

Drop each client's logo here using the EXACT filename below. The homepage
loads these automatically; any that are missing fall back to a styled text
wordmark, so the section always looks intact.

Preferred format: SVG (crispest). PNG with a transparent background also works
— if you use PNG, change the file extension in index.html for that client.

Recommended: single-color / dark logo on transparent background, roughly
240x96px or an equivalent SVG viewBox. They are shown in grayscale and turn
full color on hover.

Expected filenames:
  al-seer.svg
  mitras.svg
  magenta.svg
  al-hathboor.svg
  cosmoplast.svg
  ambassador.svg
  tssc.svg
  perfect-foods.svg
  thermozone.svg
  prestige.svg
  coolpoint.svg
  sobha.svg
